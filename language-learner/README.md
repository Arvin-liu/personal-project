# 语言学习器

语言学习器是一款基于 Python 和 Tkinter 的桌面语言学习工具，包含文章阅读、逐句朗读、词典查词与可视化句子结构等组件

项目设计面向任何母语使用者学习任意目标语言。阅读界面、句子跟随、结构标注和逐句学习流程可供不同语言组合复用；分句规则、词典、翻译和语音等具体语言组件，则可由使用者自己的 Agent 根据学习目标适配并重新编译

## 项目架构

- `app.py`：阅读界面、文章与词典模式、逐句定位、语言结构标注、历史与词汇复习
- `hermes_fast_oneshot.py`：通过使用者本机 Hermes 配置调用 AI，不保存账号凭据
- `launcher_guard.sh`：应用启动令牌、单实例子进程管理和 Python 环境查找
- `assets/app-icon.svg`：应用图标源文件
- `build_language_learner_app.sh`、`install_language_learner_app.sh`：macOS 应用构建与安装入口
- `start_language_learner.sh`、`start_language_learner_linux.sh`：源码启动入口

## 当前语言适配

当前附带的分句和查词适配以英文内容为主，翻译和部分界面示例以中文为主。项目架构可扩展到其他语言组合，但每种目标语言需要对应的分句、词典、翻译与语音适配；本仓库不承诺任意语言组合都能直接运行

## 隐私与构建

这是个人项目展示仓库，只上传项目架构、实现源码和必要组件，不包含 API Key、访问令牌、AI 服务登录配置、个人阅读记录、文章历史、缓存、语音模型、启动令牌或预编译应用包。可选 AI 服务凭据由使用者自行在本机配置

仓库源码不保证能在所有电脑上直接运行。构建可能需要带 Tk 的 Python 3、Piper 与语音模型、Hermes 或使用者选择的 AI 服务。若运行失败、缺少组件，或要适配新的语言和系统，请使用者让自己的 Agent 检查环境、补齐依赖或修改适配后重新编译

macOS 用户可在项目目录执行：

```bash
./install_language_learner_app.sh
```
